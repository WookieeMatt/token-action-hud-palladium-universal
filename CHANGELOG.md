# Changelog

## 0.1.1
- Works with Token Action HUD Core 2.1.1 (and any later 2.1.x): the dependency no longer caps Core at 2.1.0.

## 0.1.0
- First release for Palladium Universal 1.28.0+ and Token Action HUD Core 2.1: attacks by mode, maneuvers, combat rolls, saves, attributes, skills, spells, magic abilities, psionics, item rolls, devices, conditions, vehicle actions, combat utilities (Initiative, Move Action, Cover, End Turn), Rest & Heal, New Day; a Palladium Universal HUD style.
